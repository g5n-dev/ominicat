# OminiCat Studio

Studio 是运行时随附的同源浏览器控制台。运行大盘与管线调试器是两个独立视图。页面及资源随 Java 17 服务 JAR 分发，使用时无需前端构建或外部服务。

```sh
./mvnw -B verify
java -jar ominicat-server/target/ominicat-server.jar --config config/studio.yaml
```

打开 `http://127.0.0.1:8080/`。[Studio 离线配置](../../config/studio.yaml)运行三个真实处理器：RMS 能量检测、转写修订门控与多模态回显，无需提供方凭据。常规[演示](../../config/demo.yaml)仍只有一个回显阶段。模型／语音配置使用各自配置的处理器与凭据。

## 探索任务大盘

默认 `#overview` 视图按列排列已观测工作：输入内容、实际配置的各处理器以及输出。任务卡片展示有界内容预览，阶段调用展示已观测输入／输出。点击任务、调用或产出，可检查保留的日志、帧引用与交接。JVM 资源位于紧凑的次要信息栏。

Studio 使用服务端管理的 WebSocket 会话和调用方关联 ID 对任务分组。这是观测分组，不是内核任务生命周期或通用智能体抽象。没有关联信息的裸帧保持未归属。服务器暴露一条已配置管线；大盘不会虚构规划器、工作单元或模型阶段。

活动标记沿曲线连接回放实际保留的事件。回放会刻意放慢本地快速处理，并与真实执行时间分开标注。日志序号是插入顺序，不是因果全序：并发输出接纳与下游进入的记录可能以不同顺序到达。帧 ID、因果引用与调用 ID 各自保持不同含义。同步返回、异步完成或 Netty 写出都不等于业务结果已提交。

拖动模块标题可调整显示位置，不会修改执行顺序。主连线连接已配置模块的端口；任务交接通过模块外、避开滚动条的端口连接可见卡片。在任务列内使用滚轮或拖动可见滚动条，可滚动该列。拖动空白处平移画布；缩放与**重置布局**是独立控件。重置会恢复模块与列滚动位置，不删除活动记录。隐藏卡片不会留下悬空交接线。

仅当所有配置处理器都在本地示例白名单中时，才能选择**准备离线示例**来预填合成文本并进入独立 `#debug` 视图。需要显式连接后再发送示例。其他配置可通过打开调试器并启动会话检查。打开视图或详情面板绝不会启动 WebSocket 或提供方调用。减少动态效果与暂停控件会停止视觉回放。

## 操作会话

在调试器中连接以创建 WebSocket 会话，再发送文本、最终转写、图像或有界麦克风语音片段。转写的说话人／角色及媒体位置是帧数据；输入转写不会执行语音识别。麦克风采集需要 localhost 或 HTTPS 以及浏览器授权。中断会停止本地采集／播放，并请求运行时隔离当前 generation。断开会释放浏览器会话与本地媒体资源。离开调试器也会取消本地采集／播放，并使未完成的媒体读取失效。

图中展示配置的阶段顺序。流动动画由当前浏览器真实收发事件驱动，用于说明方向，不证明每个阶段都处理了某一帧。聚合 API 声明 `nodeTracing: false`：普通连接不会被追踪。可选活动记录增加阶段事件观测，但仍不提供阶段队列深度或单节点 CPU 使用率。客户端响应计时使用同一个浏览器时钟以及显式关联的首个输出，不会把客户端和服务端时间戳相减。一次输出不一定代表完整模型响应或最终结果。

运行时计数器覆盖所有连接，本地帧流则描述当前浏览器。运行时快照由并发聚合度量组成，不是原子检查点。HTTP 观测请求本身也计为 TCP 连接。待输出为零不能独自证明所有会话都已排空；接纳名额与管线工作线程度量仍需关注。

## 资源指标含义

| 视图 | 含义 |
| --- | --- |
| 堆 | 来自 `MemoryMXBean` 的 JVM 已用、已提交与最大堆 |
| 直接缓冲区 | JDK 直接缓冲池使用量／容量；不是原生总内存、RSS 或 Netty 池化预留量 |
| 平台线程 | `ThreadMXBean` 的活跃／守护／峰值计数；不含较新 JDK 上的虚拟线程 |
| 运行时长 | JVM 运行时长，可能早于嵌入式服务器实例的创建时间 |
| 容量 | 配置的每会话输入、会话／连接及消息／输出限制 |

不可用的 JVM 度量以负数表示，显示为未知。少量样本与手动浏览器流量不能证明生产容量。CPU、分配与 GC 剖析仍是独立的[可复现工作流](performance.md)。

## 配置边界

运行配置在启动时读取。Studio 不会远程替换配置或修改活跃会话的图。本地 YAML 草稿／导出与运行中的图相互独立；请补齐必需插件选项、保存文件并重启运行时后再使用。

运行时元数据刻意省略插件选项、模型名称、提示词、端点 URL、凭据引用以及配置的 token 环境变量名。从这些元数据构建的草稿不是原始 YAML 的完整备份。请显式恢复必需选项与鉴权；绝不能把浏览器 bearer token 复制进导出文件。

## 只读运行时 API

`GET /api/runtime` 返回 schema 版本 1：

| 字段 | 内容 |
| --- | --- |
| `pipeline` | 有序阶段 ID、索引与插件类型；`editable: false`、`nodeTracing: false` |
| `config` | 容量和空闲／消息／输出限制的白名单 |
| `security` | 是否要求 bearer 鉴权，不包含 token 值或环境变量引用 |
| `activity` | 是否支持按连接选择启用活动记录 |
| `runtime` | Java 版本、工作线程后端、处理器数量与 JVM 运行时长 |
| `metrics` | 帧、连接、接纳、工作线程、拒绝、失败及输出字节的聚合计数器／度量 |
| `memory`, `threads` | 上面定义的资源测量 |

该端点沿用已有 bearer 鉴权、回环 Host 校验和浏览器同源检查。非 GET 请求失败。响应使用 `Cache-Control: no-store`，不返回会话内容或逐会话标识。健康接口与固定控制台资源仍公开可访问。提供方凭据留在服务器上。鉴权和部署见[配置](configuration.md)。

快照仅在 HTTP 请求时生成。普通 WebSocket 连接没有活动处理器包装或逐阶段观测时钟。浏览器观测与渲染有自身成本，不在已记录的数值帧内核基准范围内。

## 可选活动 API

连接 `/ws?observe=1` 可记录该连接。`/ws` 和 `/ws?observe=0` 不产生活动事件。Studio 的**记录任务活动**复选框为下一条连接选择是否记录。记录是可选的，由服务器适配器实现；不会添加内核领域契约或改变帧载荷。

`GET /api/activity?after=N` 从进程内 1,024 个事件的环形缓冲区中返回至多 128 个事件。响应包含 `streamId`、`oldestSeq`、`latestSeq`、`nextCursor`、`gap`、`lost`、`reset` 和 `incomplete`。重启或历史覆盖后，必须在界面保留不完整提示。纳秒事件时间以十进制字符串表示，避免 JavaScript 丢失整数精度。时间差只在本服务器时钟域内有意义。

事件包含服务端会话、调用方会话／关联、帧／因果和调用引用、配置阶段、阶段行为、结果与预览。已知文本／转写最多保留 240 个字符；音频／图像保留元数据，不保留媒体字节。未知帧类型不会被反射或字符串化。不包含异常消息和插件选项。**文本预览就是内容**：获授权的 API 读取方可以看到本进程中其他已启用记录连接的预览。这是运行时级操作视图，不是租户隔离或持久化审计存储。演示时请使用合成内容。

活动端点与运行时端点使用相同的鉴权、Host／origin、仅 GET 及 `no-store` 边界。这个按需启用的观测器有分配和同步成本，用于有界检查，不能据此证明已追踪负载等同于未观测的内核基准。浏览器也限制保留事件、任务分组、卡片与飞行标记，并标注缺失／已淘汰历史。

| 浏览器窗口 | 上限 |
| --- | ---: |
| 全局保留活动事件／关联分组 | 512 / 48 |
| 每组保留事件／排队回放事件 | 64 / 48 |
| 可见输入／每阶段／输出卡片 | 6 / 4 / 4 |
| 视觉粒子／飞行标记 | 32 / 8 |
| 客户端帧日志／聚合样本 | 80 / 60 |

这些是本地观测窗口；触及显示上限不会取消服务端处理，也不代表业务完成。
