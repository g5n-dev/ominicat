# 场景覆盖

此矩阵将可执行机制与提供方接入、外部保证分开。它是 0.1 预览版的范围契约，不是生产认证。

| 通用场景 | 已实现机制与证据 | 适配器／外部职责 |
|---|---|---|
| 提供方原生流式转写 | `AsyncProcessor`／`AsyncEmitter`；有界下一阶段续接、generation 隔离、complete／fail／drain 测试；稳定片段／修订门控 | 实现提供方双向协议、语音端点检测和截止时间。内置 HTTP 适配器以语音片段为单位。 |
| 多音轨与说话人归属 | PCM 声道解交错；有界隔离音轨缓冲；流／采样位置；分离的说话人／角色映射；本地 WAV 载荷测试 | 提供来源归属或说话人分离；跨音轨比较前，将采集时钟归一化到同一媒体时间线。 |
| 声学预处理 | 已实现 PCM 声道拆分与 RMS VAD 能量检测；没有随附降噪处理器 | 提供方无关的预处理需要单独验证的媒体插件，声明格式、每音轨状态、缓冲与取消行为。仅凭能量阈值不能确认说话人身份，也不能分离能量相等的来源。 |
| 交互式多模态会话 | 真实 WebSocket → 本地 HTTP 转写 → 提示 → SSE 文本 → PCM 合成的集成测试；手动中断 | 真实提供方精度、声学回声控制与部署延迟。 |
| 可寻址步骤序列 | `StepFlowProcessor`、有序 Java 条件转换、版本化状态与恢复测试；可配置顺序步骤 | 持久化快照并提供匹配的版本化定义；高级应用转换仍属于策略。 |
| 单语音片段输入 | 有界 PCM 累积、显式边界刷新、未知置信度标记；PCM 与短片段回归测试 | 采集可用音频，并选择可用提供方／模型。 |
| 长录音与回放 | 确定性的信封时钟／ID 注入、已提交快照、流式 JSONL 回放／检查点示例 | 解码录音、切分语音片段、调度作业并持久化文件／采样偏移。没有内置长音频调度器。 |
| 增量策略评估 | `PolicyRule`、`policyVersion`、证据片段／时间引用、明确的保留／淘汰范围 | 提供策略并校准其解释。内置规则是确定性的字面量／标点规则。 |
| 绑定来源的区间导入／导出 | 可选 [T1a 引用](media-references.md)、生产者作用域内的片段版本、PCM 单位、显式帧边界及有界二进制往返夹具 | 提供经过验证的来源元数据与映射。整数毫秒映射不是解码器、对齐引擎或自动定位服务。 |
| 通用时间片段变更 | 转写门控支持较高版本的中间结果，但已提交最终结果拒绝事实变更；没有随附通用拆分／合并／撤回 reducer | [T1b 编辑](temporal-annotations.md)仍处于计划中。仅使用引用的消费者不需要编辑 reducer。驱动／插件负责算法、来源对齐与更正权限。 |
| 独立多维注释 | 可使用多个 `RuleResult` 值和自定义 Java 帧；没有随附通用注释目标／修订／生命周期契约 | [T2／T3 提案](temporal-annotations.md)尚未实现。词表、评审决定、授权与持久化审计仍属于应用策略。 |
| 跨轮次状态 | 有界最终结果窗口、稳定 ID 去重、角色感知提示、经过校验的快照恢复 | 保留策略与持久状态所有权。超出保留去重窗口的回放 ID 需要外部台账。 |
| 并行处理 | 具名同步分支、有界输出、共同截止时间、全成功后按顺序汇合、兄弟分支取消测试 | 异步分支使用各自独立拥有的会话。不提供首成功／竞速或法定数量汇合。 |
| 慢结果目的端 | `AsyncOutlet` 提供独立有界交付、显式饱和、失败与排空测试 | 由目的端适配器实现幂等存储、确认、重试和死信处理。 |
| 中断与连接恢复 | 带外会话中断、串行重置、过期回调拒绝、每连接所有权；会话／步骤恢复 API | 重连鉴权、持久化与外部副作用去重。旧 emitter 始终绑定已经永久关闭的旧会话对象。 |
| 过载与提供方失败 | 入口／会话／帧／输出上限；过载响应／关闭；有限 HTTP 截止时间；输出前同步降级；独立指标端点 | 上游暂停／额度协议、全局配额、熔断与分布式接纳控制。 |

## 语义约束

共同使用的转写区间必须已经共享媒体时间轴。`startSample` 仅对其来源流有效。运行时不推断跨设备偏移，也不修正漂移。只比较归一化后的时间戳；重采样和时钟映射属于媒体／驱动插件。

已提交最终片段在保留门控／窗口内不可变。提供方若更正一个已标记为最终的结果，必须使用新的、显式关联的事件，或应用定义的更正策略。允许空最终片段；是否有意义由下游策略决定。缺失置信度使用 `-1`，绝不虚构概率。

当前证据摘录保留整轮的媒体区间；匹配短语附近的子串不能证明词级音频对齐。接入方可以用可选引用值携带来源媒体身份与精确片段版本，但必须提供经过验证的元数据和映射。现有 `Evidence` 字段不变。注释／编辑／依赖 profile 仍在计划中；没有定位器服务。

异步回调输出按接纳入队操作排序。END 帧是应用标记，可能先于延迟回调到达。`finish()` 后的 `completion()` 才是排空屏障。释放传输前先等待该 future。回调操作需要有限的提供方截止时间，且必须处理 emitter 拒绝。

当前 fan-out／fallback 组合器在构造时拒绝异步子处理器。它们不会把缺失的同步方法静默解释为提供方故障。流式分支请使用各自拥有的异步会话。合作式取消无法强制不配合的 Java 插件停止，也不能撤销已进入的外部作用。

运行时快照包含已提交数据，不包含旧回调句柄或连接。新会话拥有新的私有队列；旧会话的 emitter 不能通过匹配调用方提供的 ID 将数据路由到新会话。若增加分布式结果路由器，其协议必须提供持久化隔离与幂等性。

## 验证边界

本地测试覆盖确定性规则、状态恢复、有限媒体缓冲、真实回环 HTTP／WebSocket、格式错误载荷、过载、取消与异步竞态。JMH／JFR／负载报告测量合成本地内核和回显传输。提供方原生实时 ASR、长时间多设备漂移、真实网络故障、服务配额与生产容量，需要在目标环境单独验证。
