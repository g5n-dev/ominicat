# 安全

发现疑似漏洞时，如 GitHub 安全公告功能可用，请通过该功能私下报告。避免将凭据或会话载荷放进公开 issue。

独立服务器默认绑定回环地址。对外暴露前，应配置 `tokenEnv`，在可信代理终止 TLS，并应用部署级配额。健康接口与静态调试页公开可访问；指标与 WebSocket 访问遵守已配置鉴权。浏览器传输通过子协议携带 token，避免凭据进入 URL 查询字符串。

除回环测试端点外，提供方端点要求 HTTPS。禁用重定向；传输错误消息不包含提供方响应体或凭据。请配置有限超时和大小限制。插件在宿主进程中执行可信 Java 代码；classpath 发现不是安全边界。

会话状态是暂态的。持久化、会话间授权、密钥轮换，以及超出每会话处理器所有权范围的租户隔离，仍由应用负责。生成的依赖 SBOM 是清单，不是漏洞扫描或认证。
