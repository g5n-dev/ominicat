# 提示词生成成本配对测量

Ubuntu 24.04／Java 17；同一主机、同一探针；基线 → 候选 → 候选 → 基线。

仅测合成最终转写处理：转写／片段标识构造、窗口插入、提示渲染、逐字输出校验及 Blackhole 消费。满窗口与预期字符串在计时外准备，不含管线、模型、编解码或网络。

每版每用例两个独立 JVM；每个 JVM 预热 3 × 1 秒、测量 5 × 1 秒。结果为两个 JVM 均值的平均；完整数据保留测量迭代均值范围，不是置信区间。共享运行器仍有波动，不设固定性能门禁，也不宣称生产延迟。
